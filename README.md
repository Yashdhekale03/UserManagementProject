# User Management System

## Project Overview

This is a User Management System developed using React, Spring Boot, REST API and MySQL.

The application allows an admin to manage users through a simple web interface.

## Technologies Used

### Frontend
- React.js
- JavaScript
- HTML
- CSS

### Backend
- Java
- Spring Boot
- Spring Data JPA
- REST API
- Apache POI

### Database
- MySQL

## Features

- Admin Login
- Role-based access
- Add User
- View All Users
- View User by ID
- Update User
- Delete User
- Search Users
- Upload Users using Excel
- Download Users as Excel
- MySQL database integration
